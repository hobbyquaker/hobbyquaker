Everything you find here is a hobby project, with no commercial interest behind it. I build
these things because I enjoy it, because they make my home lab and my smart home work better,
and because I learn something new with each of them.

If one of them is useful to you as well, that makes me very happy.

> I don't take donations. If you like a project, a ⭐ on GitHub is the nicest thank-you.
